CF-Codeclimb

CF-Codeclimb is a curated and up-to-date problem tracker for Codeforces Div.2 contests, inspired by the A2OJ ladder-style approach.
It focuses on providing recent contest problems, addressing the gap where many existing sheets stop being updated.

📌 Overview

Competitive programming sheets are extremely useful, but many popular ones lack recent problems, especially for ongoing contests.
CF-Codeclimb was created to solve this problem.

The project provides a static, lightweight, and easy-to-navigate tracker of Codeforces Div.2 problems, organized for systematic practice.

✨ Features

📅 Focused on recent contests (starting from 2025)

🧩 Covers Div.2 A, B, and C problems

📋 Clean, A2OJ-style structured format

⚡ Fast and lightweight (static site)

🌐 Publicly accessible and easy to use

🎯 Motivation

Most available Codeforces problem sheets:

Stop updating after a point

Do not include the latest contests

Mix problems across eras without clarity

CF-Codeclimb was built to:

Keep practice relevant and up to date

Help users practice problems aligned with the current Codeforces difficulty trends

Provide a simple alternative to outdated sheets
